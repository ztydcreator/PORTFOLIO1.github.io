# Academic Portfolio

Multi-page student portfolio and planner (HTML, CSS, JavaScript).

## Before you submit, replace these
1. "Your Name", "Your University", etc. in all 5 HTML pages (use find and replace).
2. `images/photo.svg`: add your photo as `images/photo.jpg`, then change the `src` in `index.html`.
3. `images/project1-3.svg`: use real screenshots and update the `src` and `alt` in `projects.html`.
4. `images/intro.mp4`: replace with your own short intro video.
5. Project links in `projects.html`.

## Host on GitHub Pages
Repo > Settings > Pages > Branch: main, folder: / (root) > Save.
